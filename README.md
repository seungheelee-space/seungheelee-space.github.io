# Seunghee Lee — Academic Website

Personal academic website of Seunghee Lee, Assistant Professor in the Department of Housing Environmental Design at Jeonbuk National University.

The site presents research areas, selected publications, teaching, biography and professional contact information in Korean and English.

## Website

https://seungheelee-space.github.io/

## Structure

- `index.html`: page structure
- `styles.css`: responsive presentation
- `app.js`: language switch and publication interactions
- `publications.js`: selected journal articles
- `assets/`: portrait and original illustrations

A static HTML, CSS and JavaScript website. No build step is required.
